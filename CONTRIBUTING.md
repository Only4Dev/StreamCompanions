# Contributing

English and Spanish reports are welcome. [Open an issue](https://github.com/Only4Dev/StreamCompanions/issues/new/choose) for bugs or feature requests. Check existing issues first and add new details to a matching report.

- For a bug, include the app version, whether it happens on desktop, in the portal, or in a browser source, and the steps to reproduce it. Include the streaming platform and OBS or Streamlabs version if relevant. Remove tokens and account details from screenshots and logs.
- For a feature, describe what you want to do and where the current behavior gets in the way.
- For changes, branch from `main`, use focused commits with English summaries, and run `npm test`. In a pull request, link the issue and describe what you checked. For overlay changes, include the source dimensions and a screenshot if practical.

Maintainers can ask for missing details, link duplicates, and close fixed issues with a link to the pull request. Use the [release guide](RELEASING.md) when updating a downloadable build.
